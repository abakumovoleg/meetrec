# meetrec

CLI-рекордер созвонов: пишет микрофон и системный звук отдельными дорожками, затем локально расшифровывает запись и размечает, кто говорил. Звук никуда не отправляется — из сети скачиваются только модели, один раз.

- Распознавание речи — [Whisper.net](https://github.com/sandrohanea/whisper.net) (whisper.cpp), на Mac через CoreML.
- Разделение по спикерам — [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) (pyannote + модель голоса).
- Ваша речь с микрофона подписывается «Я» без всякой диаризации; голоса собеседников разделяются только на системной дорожке.
- Созвон в Meetzone можно записать без диаризации: голос каждого участника приходит отдельной дорожкой с его именем (через расширение Chrome, см. [ниже](#запись-созвона-в-meetzone)).

Результат — `transcript.md`, `transcript.json` и `transcript.srt`:

```
[00:03:12] Я: Тогда по релизу всё. Маш, что у тебя с отчётом?

[00:03:16] Маша: Почти готов, осталось сверить цифры за сентябрь.

[00:03:22] Спикер 2: Я могу помочь, у меня выгрузка есть.
```

## Что работает

| | macOS (Apple Silicon) | Windows |
| --- | --- | --- |
| Запись (`record`, `run`, `devices`) | да, macOS 14.2+ | да, Windows 11 |
| Расшифровка (`transcribe`, `names`) | да, macOS 15+ | да, Windows 11 (GPU через Vulkan) |
| Запись Meetzone (`record --meetzone`, Chrome) | да | собирается, не проверялась |

Только Apple Silicon на Mac и x64 на Windows. Windows 10 и macOS 14 (для расшифровки) не проверялись.

## Установка

### Готовая сборка

Сборка — папка с `meetrec` (на Windows `meetrec.exe`), нативными библиотеками рядом, на macOS ещё `meetrec-capture`, и папкой `meetzone-extension`. .NET не нужен. Распакуйте или скопируйте папку целиком — по отдельности файлы не работают — и добавьте её в `PATH`.

**macOS.** Сборка не подписана: если папка пришла из браузера или мессенджера, macOS заблокирует запуск. Снимите карантин:

```sh
xattr -d com.apple.quarantine meetrec meetrec-capture
```

(или `xattr -dr com.apple.quarantine .` для всей папки). Нужна macOS 15 и новее — на 14 запись работает, а расшифровка нет: библиотеки Whisper.net собраны под 15.0.

**Windows.** Нужны Windows 11 (минимальная версия по Whisper.net) и [Visual C++ Redistributable 2022 x64](https://aka.ms/vs/17/release/vc_redist.x64.exe). Неподписанный `meetrec.exe` может вызвать предупреждение SmartScreen — «Подробнее» → «Выполнить в любом случае». Процессор — с AVX2.

### Из исходников

Нужно:

- [.NET 10 SDK](https://dotnet.microsoft.com/download);
- на macOS — Xcode Command Line Tools (`xcode-select --install`): из них собирается Swift-хелпер захвата звука.

```sh
git clone <url> meetrec
cd meetrec
dotnet build -c Release
```

Исполняемый файл — `src/Meetrec.Cli/bin/Release/net10.0/meetrec` (на Windows `meetrec.exe`); на macOS рядом с ним копируется хелпер `meetrec-capture`, на Windows хелпер не нужен. Удобно добавить алиас:

```sh
alias meetrec="$PWD/src/Meetrec.Cli/bin/Release/net10.0/meetrec"
```

## Быстрый старт

```sh
meetrec run
```

Запись идёт в `./meetings/<дата>_<время>`, в терминале — индикатор уровня обеих дорожек. Ctrl+C останавливает запись, после чего сразу начинается расшифровка. В конце meetrec покажет каждого собеседника с примерами его фраз и предложит указать имена.

При первом запуске скачаются модели (≈ 2,7 ГБ для модели по умолчанию) — дальше всё работает без сети.

## Разрешения macOS

Разрешения выдаются **приложению терминала**, из которого запущен meetrec (Terminal, iTerm, терминал IDE), а не самому meetrec. При первой записи macOS спросит:

- доступ к **микрофону**;
- доступ к **записи системного звука**.

Пока запрос висит, запись не начинается — ответьте на диалог. Проверить текущее состояние:

```sh
meetrec devices
```

Если доступ был запрещён, включите терминал в «Системные настройки → Конфиденциальность и безопасность» (раздел «Микрофон» и раздел записи экрана и системного звука) и перезапустите терминал. При запуске из другого терминала или IDE разрешения придётся выдать заново.

## Запись на Windows

Отдельных разрешений для системного звука не нужно: он пишется с **устройства вывода по умолчанию** (Параметры → Система → Звук). Если собеседников слышно в наушниках, а в `system.wav` тишина — значит, созвон играет не на том устройстве, которое выбрано по умолчанию; имя записанного устройства meetrec пишет в `session.json`.

Пока ничего не играет, Windows вообще не отдаёт звук с устройства вывода — meetrec дописывает эти промежутки тишиной, так что длительность дорожек и таймкоды остаются верными.

Доступ к микрофону Windows может запретить сам: Параметры → Конфиденциальность и защита → Микрофон, нужны «Доступ к микрофону» и «Разрешить классическим приложениям доступ к микрофону». Об отказе meetrec сообщит при старте записи — заранее Windows его не показывает, поэтому в `meetrec devices` статус микрофона всегда «сообщает только при старте записи».

Остановить запись — Ctrl+C или Ctrl+Break.

## Запись созвона в Meetzone

Для Meetzone диаризация не нужна: сервер присылает браузеру голос каждого участника отдельной дорожкой, вместе с именем. Расширение meetrec для Chrome отдаёт эти дорожки в meetrec, и в расшифровке каждый подписан своим именем из Meetzone — и вы тоже. Микрофон и системный звук при этом не пишутся.

Установить расширение один раз: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `meetzone-extension` рядом с `meetrec` (в сборке из исходников — `src/Meetrec.Cli/bin/Release/net10.0/meetzone-extension`). После установки обновите открытые вкладки Meetzone: расширение должно попасть на страницу до начала созвона.

```sh
meetrec run --meetzone
```

meetrec ждёт созвон: откройте его в Chrome — запись начнётся сама, в строке статуса видно число участников и кто говорит. Ctrl+C останавливает запись. Закрытая или перезагруженная вкладка запись не останавливает: meetrec дождётся, когда созвон откроется снова. Тишина между репликами не передаётся, поэтому дорожки участников почти целиком из нулей — так и должно быть.

Расширение отдаёт звук только meetrec на этом компьютере (`127.0.0.1:47823`) и только пока идёт `record`/`run --meetzone`. Десктопное приложение Chatzone пока не поддерживается — только Chrome.

## Команды

| Команда | Что делает |
| --- | --- |
| `meetrec record [-o <папка>] [--mic <микрофон>] [--no-mic]` | Записать созвон в папку сессии. Ctrl+C — остановить |
| `meetrec record --meetzone [-o <папка>]` | Записать созвон Meetzone дорожкой на участника (нужно расширение, см. выше) |
| `meetrec transcribe <папка\|файл.wav> [флаги]` | Расшифровать готовую запись |
| `meetrec run [флаги record и transcribe]` | Записать и после остановки расшифровать |
| `meetrec names <папка\|файл.wav>` | Указать имена спикеров в готовой расшифровке |
| `meetrec devices` | Список микрофонов и состояние разрешений |
| `meetrec models` | Скачанные модели и их пути |
| `meetrec models download <id>...` | Скачать модели заранее |

Флаги расшифровки:

| Флаг | По умолчанию | |
| --- | --- | --- |
| `--speakers N` | — | Сколько всего участников, **включая вас**. Если известно — укажите, разделение заметно точнее |
| `--threshold X` | 0,7 | Порог разделения голосов, когда `--speakers` не задан: больше — меньше спикеров |
| `--lang ru\|en\|auto` | `ru` | Язык речи; `auto` определяет язык по первым 30 с — на тишине в начале ошибается |
| `--model ...` | `large-v3-turbo` | Модель Whisper: `tiny`, `base`, `small`, `medium`, `large-v3`, `large-v3-turbo` |
| `--format md,json,srt` | все три | Какие файлы писать |
| `--no-names` | — | Не спрашивать имена после расшифровки |

`--mic` принимает имя микрофона, его часть («webcam») или uid из `meetrec devices`. Без `--mic` берётся микрофон по умолчанию.

В `run` первое Ctrl+C останавливает запись, второе — прерывает расшифровку.

## Папка сессии

```
meetings/2026-10-08_15-00-34/
  mic.wav           микрофон, 16 кГц моно
  system.wav        системный звук, 16 кГц моно
  session.json      время старта, устройства, сдвиг дорожек
  mz-<логин>.wav    вместо mic/system при --meetzone: участник Meetzone, 16 кГц моно
  transcript.md     реплики: [00:01:23] Спикер 2: текст
  transcript.json   реплики и слова с таймкодами, спикером и дорожкой
  transcript.srt    субтитры с именем спикера
```

Запись и расшифровка разделены: `transcribe` можно повторить на той же папке с другой моделью или другим `--speakers` — WAV не меняются, перезаписываются только `transcript.*`.

`transcribe` принимает и одиночный WAV — например, запись из другой программы. Тогда результат пишется рядом с ним как `<имя>.transcript.*`, а «Я» в расшифровке нет: все голоса на одной дорожке. Другие форматы сначала нужно перевести в WAV, на macOS так:

```sh
afconvert -f WAVE -d LEI16@16000 -c 1 audio.mp4 audio.wav
```

## Форматы `session.json` и `transcript.json`

`session.json` перечисляет дорожки сессии. У каждой — сдвиг её начала от начала сессии (`offsetMs`: время дорожки + сдвиг = время сессии) и, если на дорожке один известный человек, его спикер. Дорожки без спикера разделяются на голоса диаризацией.

```json
{
  "schemaVersion": 2,
  "startedAtUtc": "2026-10-08T12:00:34+00:00",
  "version": "0.1.0",
  "tracks": [
    { "file": "mic.wav", "source": "mic", "offsetMs": 12, "device": "MacBook Pro Microphone", "speaker": { "id": "me", "name": "Я" } },
    { "file": "system.wav", "source": "system", "offsetMs": 0, "device": "Системный звук" }
  ]
}
```

`transcript.json` — таблица спикеров и реплики со словами. Спикер определяется по `speakerId`, имя берётся из таблицы; `speaker` в реплике — только для удобства чтения. Идентификаторы: `me` — микрофон, `system:N` — N-й голос системного звука по порядку появления, `unknown` — голос, который диаризация не отнесла ни к кому. Имена можно менять только у спикеров с `"diarized": true`, кроме `unknown`.

```json
{
  "schemaVersion": 2,
  "speakers": [
    { "id": "me", "name": "Я", "track": "mic", "diarized": false },
    { "id": "system:1", "name": "Олег", "track": "system", "diarized": true }
  ],
  "utterances": [
    {
      "speakerId": "system:1", "speaker": "Олег", "track": "system", "start": 3.0, "end": 4.0, "text": "Добрый день.",
      "words": [ { "text": "Добрый", "start": 3.0, "end": 3.4, "speakerId": "system:1", "track": "system" } ]
    }
  ]
}
```

В записи Meetzone каждая дорожка — участник: `"source": "participant"`, спикер `mz:<логин>` с именем из Meetzone, файл `mz-<логин>.wav`. Такие дорожки не диаризуются, а имена в `meetrec names` не спрашиваются — они уже известны.

```json
{ "file": "mz-ivanov.wav", "source": "participant", "offsetMs": 624, "speaker": { "id": "mz:ivanov", "name": "Иван Иванов" } }
```

Файлы прежнего формата (без `schemaVersion`) читаются; `meetrec names` пересохраняет `transcript.json` в новом.

## Имена спикеров

После расшифровки (или позже — `meetrec names <папка>`) для каждого собеседника показываются доля речи, число реплик и несколько его фраз:

```
Спикер 1 — 24 % речи, 9 реплик
  [00:01:05] Да, я посмотрела, там два варианта, и оба нам подходят.
  [00:03:16] Почти готов, осталось сверить цифры за сентябрь.
  [00:07:40] Хорошо, тогда до четверга.
  Подсказка: Маша — так обратились перед репликой этого спикера (2 раза), [00:03:12] «…по релизу всё. Маш, что у тебя с отчётом?»
Имя [Маша]:
```

- `p` — послушать фрагмент его речи, повторное `p` — следующий фрагмент; Esc — прервать фрагмент и вернуться к вводу имени;
- Enter — принять имя в скобках, «-» — оставить номер, `q` — закончить и сохранить введённое.

Подсказка появляется, если к человеку обратились по имени и он сразу ответил. Если двум спикерам дать одно имя, они объединятся — так исправляется частая ошибка, когда один человек разбит на двоих. `names` можно запускать повторно: текущие имена будут предложены по умолчанию.

## Модели

Скачиваются автоматически при первой расшифровке, только нужные для выбранного режима, в `~/.cache/meetrec/models`. Другая папка — переменная `MEETREC_MODELS`.

| Модель | Размер | |
| --- | --- | --- |
| `whisper-large-v3-turbo` | 1,5 ГБ | Whisper по умолчанию |
| `whisper-large-v3-turbo-coreml` | 1,1 ГБ | Энкодер для CoreML, только macOS |
| `silero-vad`, `pyannote-segmentation-3-0` | < 10 МБ | Поиск речи и сегментация |
| `3dspeaker-eres2net-base`, `wespeaker-resnet34` | 25–40 МБ | Модели голоса: первая при `--speakers`, вторая без него |

Полный список с размерами — `meetrec models`. Скачать заранее, например для работы без сети:

```sh
meetrec models download whisper-small whisper-small-coreml
```

Первая расшифровка на Mac дольше остальных на ≈ 20 с — CoreML компилирует модель.

## Советы

- **Наушники.** Без них голоса собеседников из динамиков попадают в микрофон и дублируются репликами «Я». В записи Meetzone своя дорожка берётся из браузера после его эхоподавления, но и там наушники надёжнее.
- **Meetzone — через `--meetzone`.** Если созвон в Meetzone, такая запись точнее обычной: имена настоящие, голоса не путаются, распознаются только отрезки речи.
- **`--speakers`.** Если число участников известно, укажите его (вместе с собой) — без него голоса иногда склеиваются или дробятся.
- **Скорость.** 8-минутный созвон расшифровывается за ≈ 45 с на Mac с Apple Silicon; часовой на Windows с GPU — ≈ 8 мин (распознавание 1,5 мин, остальное — диаризация). На машинах без GPU берите `--model small`.

## Известные ограничения

- Если вопрос и ответ разных людей идут без паузы, они могут попасть в одну реплику.
- Слова, которые не удалось отнести ни к одному голосу, подписаны «Спикер ?».
- Смена микрофона во время записи (например, отключение наушников) может остановить микрофонную дорожку; системный звук продолжает писаться.
- Meetzone: только Chrome (и браузеры на Chromium с расширениями); десктопное приложение Chatzone не поддерживается. Созвон вдвоём, смена микрофона, фоновая вкладка и созвоны дольше часа ещё проверяются.

## Разработка

```sh
dotnet build
dotnet test
cd native/meetrec-capture && swift build -c release --arch arm64 && swift test
node --test 'browser/meetzone/test/*.test.js'
```

| Где | Что |
| --- | --- |
| `src/Meetrec.Cli` | команды, консольный вывод |
| `src/Meetrec.Core` | сессия, склейка дорожек, форматы, модели |
| `src/Meetrec.Asr`, `src/Meetrec.Diarization` | распознавание (Whisper, VAD, эвристики) и диаризация |
| `src/Meetrec.Pipeline` | конвейер расшифровки |
| `src/Meetrec.Capture.Mac`, `native/meetrec-capture` | запись на macOS: обёртка и Swift-хелпер |
| `src/Meetrec.Capture.Windows` | запись на Windows (WASAPI) |
| `src/Meetrec.Capture.Meetzone`, `browser/meetzone` | запись Meetzone: приём в meetrec и расширение Chrome с протоколом |
| `tools/eval` | стенд замеров (`meetrec-eval`) |

Сборка для распространения — self-contained, .NET на целевой машине не нужен:

```sh
dotnet publish src/Meetrec.Cli -c Release -r osx-arm64 -o publish/osx-arm64
dotnet publish src/Meetrec.Cli -c Release -r win-x64 -o publish/win-x64
```

В папке — `meetrec`, нативные библиотеки рядом с ним (на macOS — ещё `meetrec-capture`) и `meetzone-extension`; переносить её нужно целиком.

Ход работы — [`docs/progress.md`](docs/progress.md), обоснования решений с замерами — [`docs/decisions.md`](docs/decisions.md).
