# meetrec

CLI-рекордер встреч на .NET 10: запись двух дорожек, локальная расшифровка Whisper.net, диаризация sherpa-onnx.

## С чего начать

- `docs/progress.md` — что сделано и что дальше. Начинать отсюда.
- `docs/decisions.md` — почему сделано так, с замерами. Не пересматривать зафиксированные решения без новых данных.
- `meetrec — спецификация CLI-рекордера встреч.md` — исходная спека.

## Как работаем

- Спека реализуется по шагам, по одному шагу за раз. После шага — краткий итог и вопрос, коммитить ли и переходить ли к следующему. Коммитить только после согласия пользователя.
- Каждый шаг в том же коммите обновляет `docs/progress.md` и, если были решения, `docs/decisions.md`.
- Решения, где есть выбор (модели, параметры, режимы), принимаются по замерам, а не на глаз.

## Сборка и тесты

- `dotnet build`, `dotnet test` (раннер Microsoft.Testing.Platform, задан в `global.json`). Предупреждения — ошибки.
- Версии пакетов — в `Directory.Packages.props`.

## Окружение для замеров

- Модели скачаны в `~/.cache/meetrec/models`: `large-v3-turbo` + CoreML-энкодер, `tiny`, Silero VAD, pyannote, обе модели эмбеддингов. Список — `dotnet run --project src/Meetrec.Cli -- models`.
- Реальная запись созвона пользователя (8 мин, смешанная дорожка Meetily, 4–5 участников, русский): `/Users/olabakumov/Movies/meetily-recordings/Meeting 08_10_26_15_00_34_2026-10-08_12-00/audio.mp4`. Не изменять и не коммитить. Конвертация: `afconvert -f WAVE -d LEI16@16000 -c 1 <mp4> /tmp/meetrec-eval/meeting.wav`.
- Одноразовые стенды замеров — в `/tmp/meetrec-eval` (`harness` — распознавание, `diar` — диаризация, `render` — md из json). Могут пропасть после перезагрузки.
- Синтетика: русский голос только `say -v Milena`; английские TTS-голоса для диаризации не показательны.
